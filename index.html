Configuração inicial
Cole aqui as credenciais do seu Firebase para ativar o sistema

Como obter essas credenciais: acesse console.firebase.google.com, crie um projeto, vá em Configurações do projeto → Seus apps → Web e copie o objeto firebaseConfig. Depois, em Realtime Database, crie um banco e nas Regras coloque: { "rules": { ".read": true, ".write": true } }
